# 로또 발매기

로또 시스템을 구현하는 과제입니다.

## 프로젝트 개요

사용자가 원하는 금액을 입력하면 로또를 구매할 수 있고, 당첨 번호를 입력받아 구매한 로또와 비교해서 당첨 여부 & 수익률을 확인할 수 있는 프로그램입니다.

## 기능 요구사항

### 로또 번호 생성
1~45 사이에서 중복되지 않는 6개의 숫자를 뽑아서 로또를 생성하고, 오름차순으로 정렬합니다.

### 로또 구매
사용자가 입력한 금액을 1,000원으로 나눈 개수만큼 로또를 발행합니다.
 -1000원으로 나누어지지 않거나, 음수면 예외처리
 -숫자가 아닌 문자 입력 시 예외처리

### 당첨 번호 추첨
1~45 사이에서 당첨 번호 6개와 보너스 번호 1개를 뽑습니다. 보너스 번호는 당첨 번호와 중복되지 않아야 합니다.
 -중복된 당첨번호는 예외처리
 -보다 많거나, 적은 당첨번호를 뽑는다면 예외처리

### 당첨 기준 및 상금

| 등급 | 당첨 조건 | 상금 |
|------|---------|------|
| 1등 | 6개 번호 일치 | 2,000,000,000원 |
| 2등 | 5개 번호 + 보너스 번호 일치 | 30,000,000원 |
| 3등 | 5개 번호 일치 | 1,500,000원 |
| 4등 | 4개 번호 일치 | 50,000원 |
| 5등 | 3개 번호 일치 | 5,000원 |

### 결과 출력

구매한 로또와 당첨 번호를 비교해서 등급별 당첨 장수를 보여주고, 수익률을 계산해서 출력합니다. 수익률은 (총 상금 - 구매 금액) / 구매 금액 × 100 으로 계산하며, 소수점 둘째 자리에서 반올림합니다.

## 프로그램 실행 흐름

1. 로또 구입 금액을 입력받습니다.
2. 당첨 번호 6개를 입력받습니다.
3. 보너스 번호 1개를 입력받습니다.
4. 구매한 로또와 당첨 번호를 비교해서 결과를 출력합니다.

## 예외 처리

잘못된 입력값에 대해서는 `IllegalArgumentException`이나 `IllegalStateException` 같은 구체적인 예외 타입을 발생시킵니다. 에러 메시지는 `[ERROR]`로 시작하며, 에러가 발생하면 해당 부분부터 다시 입력받습니다.

### 검증 항목

**구입 금액**
- 양수여야 합니다.
- 1,000원 단위여야 합니다.
- 숫자만 입력되어야 합니다.

**당첨 번호**
- 6개의 숫자가 입력되어야 합니다.
- 각 숫자는 1~45 범위여야 합니다.
- 중복된 숫자가 없어야 합니다.
- 콤마로 구분되어야 합니다.

**보너스 번호**
- 1~45 범위여야 합니다.
- 당첨 번호와 중복되지 않아야 합니다.
- 숫자 형식이어야 합니다.

## 실행 예시

### 입력

```
로또 구입 금액을 입력해 주세요.
14000
당첨 번호를 입력해 주세요.
1,2,3,4,5,6
보너스 번호를 입력해 주세요.
7
```

### 출력

```
당첨 통계
---
3개 일치, 5등- 1개
4개 일치, 4등- 1개
5개 일치, 3등- 1개
총 수익률은 0.1%입니다.
```

## 주의사항

로또 번호를 뽑을 때는 `java.util.Random`이나 `Collections.shuffle()`을 사용해서 무작위 선택.

숫자 범위와 중복 검증은 꼼꼼하게 처리하고, 예외 메시지는 사용자가 쉽게 이해할 수 있도록 작성.

수익률을 계산할 때는 소수점 처리에 주의.
